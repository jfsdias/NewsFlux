# Personalization V2 Evaluation 01 — integrated offline results

- Audited main/base: 430026000f2fe8c7f4e823e17ab39b38254198bf
- Candidate: current Home V1 profile projection composed through the same Home session/category helpers as the Phase 2C baseline.
- Data: deterministic synthetic entries and starred-profile rows only. No Miniflux calls, mutations, persisted state, telemetry, or product-code changes.
- Top-N was fixed before execution: N=12 = first 12 article IDs in final visual order, with capacity for 3 Highlights plus 9 Category Lane slots.
- Each fixture was composed 101 times for offline latency measurements. Latency is local JS projection/composition only; it excludes API/network, React rendering, browser layout, and device performance.

## Metric contract

- Diversity: unique feed IDs and category IDs in the first N final visual article slots.
- Repetition: adjacent same-feed pairs / longest consecutive same-feed run in those N slots.
- Age displacement: promoted IDs list prior→new rank plus age relative to baseline primary; max older at rank compares the article now at each rank with the baseline article at that rank.
- Coverage: visible eligible unread IDs / eligible unread count; missing and extra are exact ID set differences; unique checks deduplication.
- Reader order: exact parity between Highlights → Category Lanes → Latest and the flattened Home Reader sequence. Exact arrays and per-fixture section IDs are in the JSON receipt.
- Disclosure: compares V1 personalizationApplied with equality of final composed IDs, lane identities/membership/order, and Latest IDs. It does not claim user-perceived benefit.
- Latency cells are median/p95 milliseconds, Phase 2C / V1.

## Results and interpretation

- **Primary parity:** PASS in all 12 fixtures.
- **Coverage, no duplicate IDs, category ID identity, and Reader visual-order parity:** PASS in all fixtures. Every eligible unread item appeared exactly once in the final composed projection.
- **Concentrated profile effects are not uniformly beneficial.** In the one-source concentration fixture, first-N distinct sources rose from 3 to 6 and adjacent repeats fell from 8 to 5; the one-category concentration fixture also rose 3→6 sources and repeats fell 8→1. Both displaced some articles by up to 24/30 minutes at equal rank. These are constructed synthetic cases, not estimates of real-user outcomes.
- **Direct current-star case:** Secondary Highlight changed from 5002 to starred 5007 while Primary stayed 5001; diversity was unchanged and adjacent same-source pairs rose 0→1. This is a position change, not demonstrated editorial gain.
- **Exact freshness edge:** the 60-minute candidate participated in its anchor group; the 61-minute candidate was outside. A focused test checks the resulting order.
- **Category lanes can amplify and mask V1 ordering.** Lane membership changed in concentration scenarios; same-title categories remained separate by ID. In the dedicated cross-category case, V1 reordered intermediate recents but lane grouping produced exactly the same final composition.
- **Disclosure defect reproduced:** in intermediate_order_change_without_final_composition_change, V1 reports personalizationApplied=true although final Home composition is identical in the compared section projection; all measured Top-N deltas are zero. No fixture produced a changed final composition with the flag absent. This warrants a narrow V1 disclosure-correctness PR before proposing V2.
- **Fallbacks:** empty profile and modeled invalid/late/stale profile fallbacks matched deterministic Phase 2C composition with no disclosure. Invalid/late/stale are harness cases selecting the existing deterministic fallback; this is not a live asynchronous/browser race test.
- **Session stability:** PASS — Load More appends only to Latest; read, star/unstar, refresh, Reader return, late profile, and stale revision preserve the committed session projection under the existing session helpers.

## Limits

These fixtures show behavior of the current helpers under controlled inputs. They do not establish relevance, satisfaction, or a population-level improvement; no human review, private account sample, live Miniflux, browser rendering, physical-device, or network latency evaluation was performed. All/Unread routes were untouched and are not ranked by this harness. No conclusion is drawn about preference signals beyond the synthetic starred examples.
