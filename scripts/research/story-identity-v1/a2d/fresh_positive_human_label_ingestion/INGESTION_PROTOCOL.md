# Fresh positive human-label ingestion

This research-only stage validates the completed human review against the frozen neutral CSV before opening the session A private identity map. It checks the map and selected pack for a 40-pair bijection, canonical pair keys, matching metadata and 80 distinct articles. The joined private output contains only review ID, pair key and human decision, sorted lexicographically by pair key.

The exact completed input, canonical labels, aggregate integrity audit and manifest are written privately through temporary files, fsync, atomic rename, hash readback and read-only permissions. The manifest pins the frozen input chain. A separate validator reconstructs membership and decisions and rechecks the frozen outputs.

Only global label counts are integrity metadata. No stratified label analysis, sufficiency-gvaluation, D2F benchmark, model execution or article-content access is authorized by this stage. Discovery and calibration gates remain unevaluated. Historical human labels and BLIND remain sealed. Human decisions remain private and are not committed.
